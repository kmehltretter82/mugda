Quick Tutorial: Mugda Syntax & Sized Types

        

          Mugda extends Martin-Löf dependent type theory with a primitive Size type,
          size successor $ i, limit/closure size # (∞, satisfying $ # = #),
          and Coquand-style dependent pattern matching with inaccessible dot patterns .e.
        

        
1. Sized Inductive & Coinductive Types

        
    
          
  • 
            Inductive upper bounds (sized data):
            Every constructor takes (i : Size) as its first index, recursive arguments at size i,
            and returns size ($ i). Subtyping is covariant: SNat i ≤ SNat ($ i) ≤ SNat #.
          
    • 
          
  • 
            Coinductive lower bounds (sized codata):
            Productive streams are defined via cofun matching ($ i) on the left and constructing
            cons i head (self i) on the right. Subtyping is contravariant: Stream # ≤ Stream ($ i) ≤ Stream i.
          
    • 
        

        
2. The Pattern-Refinement Invariant (What Broke in 2008 & How It Is Fixed)

        

          In the transfinite ordinal semantics &llbracket;D u α&rrbracket; = ∪_{β < α} F(&llbracket;D u β&rrbracket;),
          matching a value of type D u α against a constructor targeting D u ($ β)
          only justifies the inequality $ β ≤ α, not the equality α = $ β.
        

        

          When α is a limit ordinal like ω (e.g. L # emb in
          cody_nowraps.ma and cody_simplified.ma), refining a shared size variable across
          two sibling branches of a constructor or into an earlier variable's type is unsound.
          The bug-fixed engine enforces the Pattern-Refinement Invariant (checkNoccEnv + checkNoccDomains):
          a flexible size variable refined to $ s may only appear in the monotone return type of the clause!
